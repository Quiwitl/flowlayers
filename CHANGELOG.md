# Changelog

## 0.1.0 (November 2026)

First release: `Graph`, `TraversalModel` (CPU and GPU), `TraversalResult` with the full first-traversal
distribution and navis-compatible `summary`, convergence-based run count, per-run layers for target
neurons, an exact solver for small graphs, tests against the exact solver and against `navis`, and
benchmarks on random graphs and on the whole FlyWire brain.
